## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and open the generated GitHub Pages URL.

The Install button is intentionally non-functional and does not collect information or install anything.
